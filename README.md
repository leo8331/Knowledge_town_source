# 拾知小镇 · Knowledge Town

把学习资料变成一场可以探索、收集、整理和复习的游戏。当前版本：**v0.17**。

## 开始运行

需要 Node.js 22 或更新版本，无需安装依赖。仓库自带已构建的游戏；修改源码后运行 `npm run build`。

Windows 可双击根目录“开始游戏.cmd”，固定使用 http://127.0.0.1:8782/ 。继续使用原浏览器和地址，才能读取原本地存档。

```sh
node server.cjs
```

打开 http://127.0.0.1:8766/ 。根路径是门户页（推门进入 / 课程工作台 / 知识库出题器 / 其他冒险），点「推门进入」进游戏，也可以直接开 `/game.html`。第一次进入会出现游戏指导；顶部“玩法指南”可随时重开。

## 放到公网（网页访问 + 保留 API）

同一个 Node 进程既发页面又发接口，上线后网页、`/api/*`、`/kb/*` 都在一个域名下：

```sh
# 任意 Docker 平台 / 自己的服务器
docker build -t knowledge-town .
docker run -d -p 8080:8080 -e TOWN_PUBLIC=1 \
  -e API_BASE_URL=... -e API_MODEL=... -e API_KEY=... knowledge-town
```

Render 可直接用仓库根目录的 `render.yaml` 蓝图建服务。不设 `TOWN_PUBLIC=1` 时服务仍只服务本机；公网模式对花钱的接口按 IP 限额。完整步骤、环境变量、持久化与排错见[在线部署说明](docs/DEPLOY.md)。

内置AI资料覆盖139个中英文知识单元。新版教学5分为基础、示范、引导练习与独立应用；整章交付后开启正式练习、复习与错题，测验90%算通关。旧课程和旧进度保留，主动选择新版才建立独立记录。右上角可选中文、English或中英双语，六章均支持独立重玩；未来机关可以查看开启条件，操作仍按当前阶段开放。

本地版已集成物件小游戏：找到知识物件后，以规则实验、参数操作、证据判断、样本拟合、分组等不同玩法加深理解，再手动收藏。已审范围为23个不同源知识单元、11类控件，包含原课程1.1的22项；不代表全部139项或任意导入教材都有小游戏。双击原“开始游戏.cmd”，已有8782页面按F5加载本次更新；实际验收范围见[本轮集成报告](flow/tasks/D-six-hour-integration.report.md)。

课程生成先建立知识库、核对来源与缺口，再生成游戏章节，详见[玩法与知识设计](docs/GAME_GUIDE.md#知识与交互设计)。

## 接入自己的资料

右上角“导入知识库”可选择或拖入多份文字文件，也可直接粘贴正文；清单支持追加、替换同名文件和移除，最多50份、合计7MB。PDF或扫描件需先提取文字。

复制 `.env.example` 为 `.env`，填写服务地址、模型和密钥，重新启动。支持兼容 Chat Completions 的可配置接口；生成内容先预览、核对后加入课程。未配置接口时，内置课程和独立游戏照常可玩。密钥仅由本机后端使用。

### Windows 一键启动

在项目根目录双击 `开始游戏.cmd`（或 `start-game.cmd`），自动启动本机服务并在默认浏览器打开游戏。启动器会自动寻找 PATH、常用安装目录及本机 Codex 已有的 Node.js 22+，不需要安装 npm 依赖。若运行时在自定义位置，可用 KNOWLEDGE_TOWN_NODE 指向现有 node.exe。固定使用 `http://127.0.0.1:8782/` 以保持固定存档地址；重复双击会复用已启动的游戏。存档还区分浏览器：从内置浏览器换到默认浏览器不会自动带入进度，可继续刷新原内置标签，或在成长手记中导出/导入备份。启动失败时窗口保留错误，日志在 `artifacts/runtime/launcher.log`。若端口被其他应用占用，会提示处理，不会擅自切端口或结束其他程序。
