## 问题与改法

旧 `assemble-independent-check` 的题干完整给出reserve→fit→evaluate，原排序最多检查是否照排。B5 `1.1-lesson-13` 已改分类，但卡片直写“训练样本”“未提供给训练的保留样本”，仍偏基础识别。本候选不追求再换一组标签：审查三份实际使用日志，分别判断数据是否影响当前权重、是否支持目标环境；再计算有资格用于本次目标评价的那份记录表现。

第一步：把甲（旧环境、未影响权重）、乙（名称测试但用于改权重）、丙（目标环境、冻结后独立评价）分到三种证据边界。不是挑最高分。第二步：只核算独立且用途相符记录的正确率和错误条数；保留“只是这一批数据表现、没有给上线阈值”的边界。
