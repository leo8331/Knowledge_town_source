# 拾知小镇：玩法、知识设计与课程生成

> 这是当前唯一的玩法与设计说明。原来的《知识与互动设计》已合并到本页末尾；早期集成历史在 [archive/history/INTEGRATION-history.md](../archive/history/INTEGRATION-history.md)。

## 现在的体验（2026-10-24）

**一节一间小密室。** 每个学习小节的场景里藏着一条可选的密室线索链：看过几件知识物件后，旧抽屉松开 → 取出黄铜钥匙 → 打开上锁的木箱 → 三张纸条组成密码锁（每张缺一个词，选对才开）→ 若这一节的概念有先后顺序，还要把它们依次放进顺序石板 → 取出线索卡并得到 1 枚学习币。选错不扣任何东西，没有次数限制，已对上的格子会保留，并给出“它属于哪一类”“想想这个例子”这样的提示，不直接给答案。

**这是复习性的支线，不是考试。** 它不计入本节应用，不确认基础，也不影响章末 90% 通关；奖励只有每间密室一次的学习币和一张回顾卡。

**知识连线。** 阅读任意知识物件时，下方会列出：先要懂什么、接着会用到什么、容易想错的点、同一家族的其他概念。这些来自课程自带的先修关系和易混点，只做展示。“我的旅程”里还有“本节知识地图”，把一节的概念按先修关系摆成一张图，看过的会亮起来。

**进度一眼可见。** 页头第二行常驻四章进度和“下一步该做什么”，点它会把镜头带到下一件要找的东西；“我的旅程”按章显示 找到 / 整理 / 交付 / 练习 / 通关 的当前阶段。展示只读取已有的记录，不改变任何判定。

**回来有理由，但没有惩罚。** “今日订单”是三道几分钟的小题（取自你已读过的概念，没读过就从全课程里取），每天一次奖励 1 枚学习币。“这周来了几天”只数来过的日子，中断不会清零任何东西。隔了一天以上再回来，会轻轻提示上次在哪、有几件复习在等。

**声音。** 默认关闭。页头“声音”可开关，并分别调背景音乐和点击音效的音量。全部由浏览器现场合成，不下载任何音频文件；背景音随场景换一点音色。偏好单独存放，不进存档、不影响备份。

这些新增状态保存在存档的 `escape` 和 `journey` 两个可选字段里，读档时宽松修复：字段损坏只会丢掉这部分，不会让整份存档无法打开。


## 本地概念小游戏（2026-10-23，已更新CMD入口）

双击项目根目录“开始游戏.cmd”，本地试玩地址为 http://127.0.0.1:8782/ 。本轮仍在集成，具体可玩范围以最终本地更新说明为准。

已绑定小游戏的知识物件：先在场景找到并阅读，再点“进入概念小游戏”。依据概念操作实验、观察结果、修正判断，通过后返回物件页手动收藏；基础确认也须先完成该小游戏。没找到的物件不能从知识列表直接收藏。完成小游戏不会自动收藏、完成本节应用或授予章末90%测验通过。

返回、切语言和刷新会保留操作记录与未提交草稿。可在物件页选择“重新开始本物件的小游戏”，确认后只清该小游戏记录，原收藏与章节成绩保留。旧存档已收藏的物件不追溯取消；没有对应已验游戏的自定义知识保留原流程，不伪称已覆盖。

旧档已收藏或归档的已绑定物件，也可从知识素材箱回看，点“体验概念小游戏（原收藏保留）”，不用为体验新玩法重玩整章；这不会补写历史发现记录或直接给出小游戏成绩。新物件仍须先在场景找到。

原1.1的规则、参数、证据、样本、分组等不同玩法已按实际知识绑定接入；当前覆盖23个不同源知识单元、11类控件，不能视为全部139项或任意导入教材均已更新。下面“读后即可收藏”的旧说明仅适用于未绑定概念小游戏的路线。

## 新版教学5（2026-10-22）

新建内置课程默认进入探索版5。已有旧版存档可继续玩，点击“进入新版教学5（旧课程和进度保留）”另建新版课程，旧课程仍可切回。两种课程的1.1范围不同，不共享活动答案和完成记录。

每节先自由查看、寻找场景知识物件；找到后才能收藏，收藏可选。完成基础确认后，依次看推理示范、做引导练习，再完成独立应用；部分短练习会在读完其所需知识后提前开放，不必重复完成同一引导。错误反馈可回看相关知识并返回原草稿，具体诊断后的重试属于订正。整章应用完成并提交后开放正式练习，通关仍需90%。四个学习章可独立进入，海边、冬季及三个经典入口保留。

下文旧花房配对等说明只适用于旧版课程，不能代表新版全部教学形式。


在项目目录执行 `node server.cjs`（安装了npm也可用 `npm start`），打开 http://127.0.0.1:8766/ 。无需安装依赖。需要 Node.js 22 或更新版本。直接打开 dist/index.html 也能体验内置课程，但生成课程需要本机后端。

## 学习流程

首次进入会显示旅行指南，可选“带我玩一次学习章”“先去海边冒险”或自行选择章节。跟随学习引导时，屏幕角落会根据实际阅读、收集和整理进度提示下一步，可随时关闭。第一次进入各章有入章说明；顶部“玩法指南”和冒险章里的“怎么玩”可以反复查看，跳过引导不会跳过学习或任务条件。

游戏包含六个可自由进入的独立章节：四个学习章，以及海边、圣诞两个独立冒险章。原内置路线为13小节，AIB完整路线为38小节，不要把两条路线的同号任务视为相同内容。章节之间没有前置通关门槛，可以交替游玩，各自保留进度；章内小节按顺序推进。场景装置可定位未读素材、整理背包、重读已归档内容。知识、未来机关的可查看状态和可操作状态分开，未到阶段可查看开启条件，但不提前推进任务；整章交付后才开放正式练习。

场景中的装置使用“萤火标本簿”“叮当百宝台”“猫头鹰密柜”等小镇名字，打开后以小字说明学习内容。不同装置使用不同图标、布局与整理反馈。部分装置按知识类别分组；路线图表达学习顺序，不宣称业务流程只有一种顺序。知识阅读之后，本节使用对应知识的情境操作检查理解；全章交付后再进行正式练习与测验。

原始兼容课程（不是教学4/5）保留直接阅读收集与场景部件组装：先查看装置、寻找部件，阅读并收集后放入插槽。该旧路线的Task 1.1“星芽花房”包含22个知识单元及概念配对，其余任务有预算、收益、权限、数据修复等操作。旧存档仍能继续，但这些旧玩法不能代表当前教学5或本轮概念小游戏。

顶部“六章地图”和场景章节按钮可进入第五章“贝壳来信湾”（收集碎片修复风铃、转动三面航标、按暗号寄出明信片），以及第六章“铃铛不眠街”（按缎带投递礼物、联动开关点亮街灯、按线索奏响钟声）。每章有三项顺序任务、物件背包、装置交互和通关反馈，支持拖放，也支持先选物件再点目的地。两章没有课程题目；任务进度独立保存。按 Escape 返回原章节。

海边航标、雪夜街灯、来信印记与钟声都直接摆放在场景中，未到阶段的机关也可点击查看开启条件。两章还分别保留两段可选小故事：拧开漂流瓶、退潮观察池底；为火车调整道岔、给雪人换衣帽。完成后留下风景手帐纪念，支线、换装和主线进度分别保存。

顶部“其他冒险”和六章地图下方可进入原版《失落的档案馆》《星叶群岛》《林间寻物社》。三套独立玩法及原有浏览器存档保留，没有被新章节替代；进入后可通过“返回拾知小镇”或页面品牌链接回到首页。

知识素材箱保留章节和小节结构，答题时也能返回查阅。复习按练习记录安排，错题需独立答对才移出修复列表。章末测验覆盖本章全部题目，记录每题首次提交，准确率至少90%才标记本章通关，与其他章是否能进入无关。切换学习章节会保留阅读位置、当前练习物件和未完成的章末测验。学习与冒险记录保存在当前浏览器中。

## 配置课程生成接口

复制 `.env.example` 为 `.env`，填写 `API_BASE_URL`、`API_MODEL`、`API_KEY`，重新启动服务。服务地址应为兼容 Chat Completions 的API基础地址；后端会调用其 `/chat/completions`。密钥只在本机后端使用，不放进网页或仓库。`.env` 已被忽略。

默认使用JSON对象输出；若服务不支持，可设置 `API_JSON_MODE=false`。根据模型选择 `API_TOKEN_PARAMETER=max_tokens` 或 `max_completion_tokens`。其他参数见示例文件。接口协议参考 [官方 Chat Completions 文档](https://platform.openai.com/docs/api-reference/chat/create)。

右上角“导入知识库”直达课程生成，也可从“我的材料”进入。支持选择或拖入多份TXT、Markdown、CSV和JSON文本，或直接粘贴正文；每次选文件会追加到清单，同名文件替换，可单独移除。最多50份、合计7MB，PDF和扫描件需先转文字。关闭再打开会保留本页清单与课程名称，刷新页面会清空。后端分块处理材料，输出四章课程并校验知识与题目引用是否存在于原文。生成后先预览，确认后才导入新课程。上传内容会发送到所配置的模型服务。当前没有填写真实服务和密钥；已验证本地模拟服务的完整生成流程，尚未验证真实模型的效果与费用。

## 来源与验证范围

## 双语、重玩与知识库

右上角“中文 / EN”切换小镇界面、内置知识与200道练习的显示语言，不改变答题判分或进度。学习章底部“重玩本章”、冒险章顶部“重新开始本章”支持独立重玩；确认后只重置本章。自定义课程先逐项建立知识库，有来源或定义缺口时停止生成，请补充教材正文。完整行为、来源与维护方式见[知识与交互设计](#知识与交互设计)。

## 保存与完整备份

使用一键启动器保持同一个本机地址（127.0.0.1:8782）和同一个浏览器。进度保存在该浏览器中，更换地址、浏览器或清除网站数据不会自动同步。

打开“成长手记”，点“导出完整备份”保存JSON。恢复时仍在“成长手记”点“恢复备份”，选择该JSON，核对后点“确认替换为这份备份”；也可取消保留当前记录。恢复会替换当前浏览器的整份小镇记录，建议先导出当前备份。无效备份不会覆盖当前进度。

“导入知识库”用于生成新课程，“导入已整理的游戏课程”用于加入课程，“恢复备份”用于恢复整份记录，三者用途不同。导出单份材料也不包含整份游戏进度。

## 知识与交互设计
### 内容清单与来源

内置课程按大纲的四章、13 个 Task、58 项技能组织。`content/knowledge-inventory.json` 是可审阅的知识清单：139 个单元逐一记录所属任务、技能、术语、定义、示例、英文释义、出处和交互方式。游戏由同一清单构建，不用装饰按钮数量充当知识覆盖率。

Task 1.1 包含 22 个单元，按“AI领域与学习方法”“模型与运行机制”“数据形态”“数据质量”“验证与泛化”“词汇与标准”分组。先学习 AI、ML、深度学习、神经网络、NLP、计算机视觉和生成式 AI，再理解算法、模型、训练、推理，以及数据和验证。单元标识保持稳定，重排不丢失原有收集记录。

原有教学释义与例子依据用户大纲和伴读资料编写；新增基础概念查阅了 [IBM AI](https://www.ibm.com/think/topics/artificial-intelligence) 和 [IBM Machine Learning](https://www.ibm.com/think/topics/machine-learning)（2026-10-20）。[NIST AI RMF](https://airc.nist.gov/airmf-resources/airmf/0-ai-rmf-1-0/) 用于核对 AI 系统与风险治理的概念边界。ISO框架条目另外核对了[ISO/IEC 42001](https://www.iso.org/standard/42001)与[ISO/IEC 23053](https://webstore.iec.ch/en/publication/77056)的官方简介。它们不是官方考试题库。覆盖所有列出的技能，不代表已经穷尽考试可能涉及的知识；其余12个任务新增63个细分单元，逐项覆盖其52条技能目标；保留全节概览，另拆分定义、示例与易混边界。官方来源登记在 `content/knowledge-sources.json`，涵盖AWS学习指南、架构文档、NIST风险框架与Microsoft组织采用资料。内容是面向用户大纲的教学整理，仍需持续由领域人员审阅。

### 学习与理解检查

1. 阅读型物件直接展示定义与示例，读完可收集。
2. 组装型物件提示寻找部件；返回场景后出现这件物品的三个部件，每个可展开阅读。收集后可拖放到插槽，也可先选部件再选插槽；放错不消耗素材。不同物品分别使用齿轮、匣壳、摇柄，种子、陶盆、水壶，镜片、镜筒、镜柄，或罗盘部件。
3. 将知识物件交付本节装置。计数为已整理知识单元数/本节总数。
4. 收齐后启动本节专用活动。仅Task 1.1使用概念—定义配对，最多五组一页。其余12节依据知识目标使用42轮情境操作，详见下表。
5. 本节每一轮操作与判断通过，才允许完成小节、收好成果并刷新下一节。整章基础交付后才开启正式练习、复习、错题和90%章末测验。

这些操作是读完后的形成性理解检查，不是要求初学者先答题才能看到知识。知识素材箱始终允许重读已收集的内容。

### 双语与重玩

右上角语言菜单可以直接选择中文、English、中英双语。双语模式将当前小镇界面、内置学习内容、活动与200道练习的对应中英文同时显示；在阅读页也能切换并继续当前内容。题干、选项、配对、流程、填空和情境文字有对应英文；翻译仅影响显示，不改变判分用的标识与答案，语言选择自动保存。三个经典独立游戏保留原版中文界面。用户手工导入且没有英文版本的原始资料保留原文，不以未经核对的翻译替代。

六章分别有重玩入口，游戏内说明重置范围并要求确认。学习章重置本章收集、学习任务与章末成绩；冒险章重置本章主线与风景手帐。其他章节不变。

新增知识后，曾完成旧版相关小节的存档会保留已读与已整理素材，将旧成绩保存在历史字段 `previousResults`，重新开放需要补充知识的小节；其他章节保留。

### 自定义课程流水线

配置本机API后，每个材料片段依次执行两次模型调用：

1. **建立知识库**：提取明确知识单元、定义、引用、出处、中英文内容，并报告只列目标却缺少解释的缺口。逐字引用必须在上传片段中核对成功。
2. **编排课程与交互**：以已核实知识库组织四章、学习卡与练习；最终逐项核对每个单元的标题、中英文定义和引用是否保留。要求各节明确列出活动与技能映射，整套课程至少包含三类操作控件；缺少活动、遗漏目标或非法判定结构不能加入。缺口未补、引用不实、内容改写或条目遗漏都会阻止加入游戏。

当前后端不会自动联网抓取补充资料。若上传文件只是大纲，应补充教材、讲义或权威资料正文；不能让模型把未经查证的信息伪装成材料内容。生成结果仍需用户预览核对后才加入，API密钥仅存在本机环境变量。

### 阶段与图标职责

基础学习轮只显示知识物件、组装部件与学习装置；普通工具、植物触发点与后续答题物件等待基础交付后刷新。答题轮对答案图标保留独占用途，同款普通工具不同时摆放。回到基础学习时再次移除第二轮物件，其他章与存档保持独立。知识图案约40px、种子29px、部件36px，透明按钮保留60×64px点击范围；悬停标签同步缩小。

三模式显示由 `language-engine.js` 管理词对，`town-i18n.js` 在显示层生成对照文本。操作控件和答案ID保持原值，不把译文写回判分数据。未知译文保留原文；三个经典独立游戏保留原版语言范围。
