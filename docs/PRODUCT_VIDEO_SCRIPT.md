# 拾知小镇｜产品介绍视频录屏脚本

版本：v1，2026-10-24。用途：由你录制产品使用介绍，配合屏幕操作讲清特色。与路演演讲稿分开，重点是“怎么用、为什么这样设计、已有案例能展示什么”。

建议时长：约5分钟，按实读和操作节奏调整。画面操作是录制提示，不用念；旁白可直接读。主线为：**先看已有案例，再看制作流程，最后解释两者背后的架构。**

## 1. 开场：这个产品做什么（0:00—0:20）

**画面操作**

从首页开始，短暂停留产品名，再切一小段内置小镇画面和工作台总览。不要长时间展示静止封面。

**旁白**

> 这是拾知小镇，一个把学习资料制作成互动学习体验的产品。老师或内容提供者可以在工作台准备课程，学习者则进入场景，通过探索、操作和练习学习。下面先看已经做好的游戏案例，再演示一份资料如何进入课程制作流程。

**字幕重点**：资料 → 互动课程 → 学习体验。

## 2. 特色一：已经做好的学习游戏案例（0:20—1:05）

**画面操作**

进入已有的AI学习案例。先给地图全景，再切近景点击一个尚未收藏的知识物件，打开内容与操作。演示时优先选你已经确认能顺利完成的概念小游戏。

建议以“规则系统”类小游戏为例：用实际控件改变输入，观察规则判定；展示一个边界条件。如果当前课程未提供这个物件，就选实际可见的另一项小游戏，并将下面例子同步改成对应内容，不为镜头虚构操作。

**旁白**

> 第一个特色，是我们已经做好的学习案例。知识被放进场景中的物件和任务里，玩家可以探索，也能在操作中理解概念。
>
> 比如学习规则系统，重点是理解条件怎样决定结果。这里可以用改变输入、观察结果的操作，帮助理解规则和边界，再通过任务检查判断。对于已经接入概念小游戏的新物件，完成对应操作后，才能收藏。
>
> 我们希望每一次互动，都和正在学习的内容有关。

**字幕重点**：发现物件 → 理解概念 → 操作验证 → 收藏。

## 3. 案例如何组织学习（1:05—1:40）

**画面操作**

依次展示章节入口、知识回看、练习或错题入口。演示中文与英文/双语切换。只需选一个界面展示切换，不重复切遍全部页面。

如展示六章导航，用字幕明确“四个学习章＋两个探索场景”。不要把所有章节都点开或在镜头里从零通关。

**旁白**

> 这套内置案例有四个学习章节，以及两个探索场景。学习内容按章节组织，配合基础学习、应用、练习和复习；已经学过的知识可以回来查看，答错的内容也有复习入口。
>
> 目前，内置课程整理了139个源知识单元，其中23个单元接入了11类概念小游戏，还支持中文、英文和双语显示。这些案例让我们能够检验不同知识适合怎样的互动。

**字幕重点**：章节组织 / 多种操作 / 回看复习 / 三种语言显示。

## 4. 怎么用：选择场景，准备资料（1:40—2:15）

**画面操作**

回到首页进入课程工作台，展示四步导航。

第一步选择一个已有模板或已经生成好的场景；第二步粘贴一份短资料。建议使用文末“森林邮局”样例，让后面的题目与这里的资料对应。

如果要展示生成场景，可录下真实提交和完成过程，剪掉等待并加“生成过程已加速”字幕。主片不必等待现场调用完成。

**旁白**

> 制作课程从工作台开始。第一步选择场景，可以使用已有模板，也可以通过模型生成场景。第二步导入学习资料，说明要学的内容。
>
> 这里用一段森林邮局的规则说明做演示：超过两千克的包裹走人工柜台，两千克及以下走自动柜台。接下来，我们就围绕这份资料制作练习。

**字幕重点**：第一步 选场景 / 第二步 导入资料。

## 5. 怎么用：完整出题器，检查后使用（2:15—2:55）

**画面操作**

点击第三步，进入原有的完整“知识库出题器”，让观众看到资料已经带入。

展示独立的出题模型选择、受众、题量与六类题型设置，然后打开事先真实生成并检查好的同一主题题库。停留一题，展示题干、答案与解释的审核视角。

最后点击顶部“使用此题库，继续预览 →”。

**旁白**

> 第三步进入完整的知识库出题器。资料会从工作台带过来，我们可以设置学习对象、题目数量和题型。场景生成与出题可以分别选择模型，按各自任务进行配置。
>
> 这里支持单选、多选、排序、分类、连线和数值六类题型。生成之后，先检查题目和解释，再决定使用哪一份题库。
>
> 现在打开的是根据刚才资料预先生成的题库。确认后，点击顶部按钮，把它带回工作台。

**字幕重点**：第三步 生成、检查并选定题库 / 人工审核后使用。

## 6. 怎么用：预览、进入地图、完成任务（2:55—3:30）

**画面操作**

第四步展示课程名称和原场景，点击“打开完整预览”，再点“开始互动任务”。在地图上打开题目，回答“恰好两千克”的问题，展示反馈与完成进度。

如果时间允许，刷新一次，保留画面中的已完成进度。录制前确认题库确实含有该题；若不同，以实际题目为准修改旁白。

**旁白**

> 第四步可以检查课程预览，再进入互动地图。刚才选好的场景会保留下来，题库里的题目则成为地图任务点。
>
> 这道题问，包裹恰好两千克应该走哪里。根据资料，它属于“两千克及以下”，应该走自动柜台。完成后，页面会记录进度，刷新也可以继续。
>
> 这样，我们就走完了资料、题库、场景和实际作答这条流程。

**字幕重点**：第四步 预览与试玩 / 任务反馈 / 进度保存。

## 7. 特色二：背后的分层架构（3:30—4:35）

**画面操作**

插入一张简洁结构示意图，逐层高亮。可在剪辑软件里用文字框完成，不必录代码或目录。建议按以下三层绘制：

```text
知识层：材料、知识结构、内容依据
                   ↓
教学层：学习目标、示范、操作活动、题目与反馈
                   ↓
呈现层：场景、物件、界面与任务

连接方式：统一数据约定 → 校验与转换 → 可玩的课程
```

先用内置案例的一个物件对应三层，再切回工作台，画出当前已跑通的通路：

```text
资料 → 出题器题库 → 转换成地图任务 → 场景预览与作答
场景选择 ────────────────────────↗
```

两张图分别标注“整体分层设计”和“当前工作台已跑通流程”。

**旁白**

> 第二个特色，是背后的分层架构。
>
> 我们把知识、教学设计和游戏呈现分开：知识层处理学什么、内容依据是什么；教学层处理用什么活动帮助理解、怎样练习和反馈；呈现层把这些内容放进场景、物件和任务。
>
> 中间通过统一的数据约定、校验和转换连接起来。这样，内容更新时不需要把整个场景重做，换场景时也能继续使用已有内容；新的教学互动也可以逐步加入。
>
> 目前工作台已经跑通的是资料、题库到互动地图的链路。内置案例里更丰富的小游戏，有专门的教学设计和审校。我们正把这些经验沉淀为可复用的能力，逐步扩大新资料能够生成的体验范围。

**字幕重点**：知识 / 教学 / 呈现分层；内容与场景可复用。

## 8. 收尾：案例验证体验，工作台承接制作（4:35—5:00）

**画面操作**

左右或前后切换“已有案例的实际操作”和“四步工作台”，最后停在产品名与一句话介绍。不要以代码、错误提示或等待进度结束。

**旁白**

> 拾知小镇的两个重点，一个是已经可以体验的学习游戏案例，另一个是让内容、教学和场景能够分别完善、重复使用的架构。
>
> 我们希望把这些能力交给有现成资料的讲师和培训团队，让他们能够制作、检查和试用自己的互动课程。这就是拾知小镇。

**结尾字幕**：拾知小镇 Knowledge Town｜把学习资料做成互动学习体验。

## 录制前准备

1. 双击原“开始游戏.cmd”，从本地8782首页开始；工作台、完整出题器和内置案例分别准备好。
2. 统一使用一份资料、一个场景和一份真实题库，先完成一次全流程彩排。已有题库也可以使用，口播明确为预先生成样例。
3. 内置案例提前选好一个能完成的概念小游戏、一个回看页面和一个语言切换界面。具体操作以当前所选课程为准，避免在镜头里临时找入口。
4. 检查任务是否已完成；如需重录，使用支持的重玩入口或单独的演示浏览器资料，不清理日常存档。
5. 建议横屏录制，关闭通知，保持文字可读。只展示模型名称，不展开密钥、服务私有配置、个人目录或无关资料。
6. 分段录制，再按脚本拼接。等待生成可剪掉；如果展示状态变化，加“等待过程已剪辑”字幕，保留真实结果。动态图要录连续画面，不用静态截图冒充效果。
7. 主片先保证一条流程清楚，再加案例细节。六类题型只需展示设置，实操选一至两类，不要求把所有类型挤进五分钟。

## 可直接用于演示的短资料

标题：森林邮局的包裹分流规则

> 森林邮局使用规则系统分流包裹：重量超过2千克的包裹走人工柜台，2千克及以下走自动柜台。因此，恰好2千克的包裹应走自动柜台。规则系统把明确条件映射到动作。当输入、规则版本和相关状态相同时，判定结果应相同。要复现一次判定，应记录输入、规则版本和相关状态，不能只保存输出。

建议生成少量题目用于演示，选能明确对应这段资料的题，先检查答案和解释。该资料只作演示素材，不代表客户授权案例。

- “已有案例”与“现场新生成课程”分别标注。不要把内置139个源知识单元和23个小游戏单元，说成刚上传资料就全部自动生成。

- 现在演示的是本地可运行产品。没有实际公开部署时，不把本地预览称为任何人可访问的公开发布链接。
- 不宣称已有自主多智能体剧情、教师集中数据后台、付费客户或学习效果提升，除非后续有真实实现和记录。
